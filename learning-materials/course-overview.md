# 课程概述

## 课程目标

- 理解大数据处理的基本概念、技术栈与典型应用
- 掌握机器学习与深度学习的核心算法
- 能用主流工具（Hadoop / Spark / PyTorch / TensorFlow）完成数据处理与建模任务
- 培养数据思维与工程实践能力

## 主要内容

1. **大数据基础**：分布式存储（HDFS）、分布式计算（MapReduce / Spark）、流处理（Kafka / Flink）
2. **机器学习**：监督/非监督学习、特征工程、模型评估
3. **深度学习**：CNN / RNN / Transformer、迁移学习
4. **实战**：用真实数据集完成端到端项目

## 推荐学习路径

理论 → 代码复现 → 小项目实战 → 大作业
